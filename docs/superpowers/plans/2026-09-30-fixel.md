# Fixel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Fixel, a macOS terminal AI: double-tap Right Option → drag-select a screenshot → a mode-aware answer streams into Fixel's own Terminal window, with case-file memory, one-key actions, stack shots, and learn mode.

**Architecture:** One asyncio process in a dedicated Terminal.app window. A Quartz listen-only event tap (background thread) detects the double-tap and feeds an asyncio queue. A capture worker runs `screencapture -i` and fills a tray. The prompt loop (prompt_toolkit) sends the tray to a pluggable provider (Claude or Gemini), and Rich renders the stream. Pure logic (`hotkey.DoubleTapDetector`, `parse`, `session`, `casefile`) is separated from OS glue (`capture`, `terminal`, `permissions`, `actions`) and from the UI.

**Tech Stack:** Python 3.12 (Homebrew), anthropic 1.x, google-genai 2.x, prompt_toolkit 3, rich 13+, pyobjc-framework-Quartz, keyring, sqlite3 FTS5, pytest + pytest-asyncio.

**Spec:** `docs/superpowers/specs/2026-09-30-fixel-design.md`

## Global Constraints

- macOS only; Python ≥ 3.11 (`/opt/homebrew/bin/python3.12`, venv at `.venv`).
- Default model alias `sonnet` → `claude-sonnet-5-5`; `opus` → `claude-opus-5-5`; `gemini` → `gemini-2.5-flash`. All are overridable in `~/.fixel/config.toml`.
- API keys live in the macOS Keychain (service `fixel`, usernames `anthropic` / `gemini`). The `ANTHROPIC_API_KEY` / `GEMINI_API_KEY` env vars take precedence. Never write keys to files.
- Fixel state lives under `~/.fixel/` (override with `FIXEL_HOME`); notes go to `~/Fixel Notes/`.
- Double-tap window 0.4 s; tray max 5 shots; images longer than 1568 px on their long edge are downscaled.
- ⌃R never runs anything without the user typing `y`.
- Reply header contract: `MODE: <error|math|doc|ui|general>` / `KEY: <line>` / `---`.

## Review Focus

1. **Paths with spaces.** The repo lives in `…/Personal Projects/…`, so the Terminal.app launcher must quote the interpreter path inside AppleScript. → Task 7 `test_launch_command_quotes_paths_with_spaces`.
2. **Huge Retina screenshots** (e.g. 3024×1964) must be downscaled before upload. → Task 7 `test_large_capture_is_downscaled`.
3. **The header split across stream chunks, or missing entirely.** The UI must never show raw `MODE:` text. → Task 3 `test_streamed_char_by_char_converges`; Task 9 `test_stream_answer_parses_and_renders`.
4. **Option used in chords** (⌥→ word-jumps), and triple taps, must not trigger capture. → Task 2 `test_option_chord_is_not_a_tap`, `test_triple_tap_triggers_once`.
5. **A network failure after partial output** must keep the screenshots and typed text so Enter retries. → Task 10 `test_provider_failure_mid_stream_restores_tray_and_text`.

````python
"""Settings (~/.fixel/config.toml) and API keys (macOS Keychain)."""

from __future__ import annotations

import os
import tomllib
from dataclasses import dataclass, field
from pathlib import Path

import keyring

KEYRING_SERVICE = "fixel"
ENV_VARS = {"anthropic": "ANTHROPIC_API_KEY", "gemini": "GEMINI_API_KEY"}

DEFAULT_CONFIG_TOML = """\
# Fixel settings. Delete a line to fall back to its default.
default_model = "sonnet"        # sonnet | opus | gemini
notes_dir = "~/Fixel Notes"
recall_threshold = 0.6          # 0-1: how similar a past case must be to show "Seen before"
double_tap_window = 0.4         # seconds allowed between Right Option taps
thinking = true                 # Claude adaptive thinking: better answers, slightly slower
max_tokens = 16000

[models]
sonnet = "claude-sonnet-5-5"
opus = "claude-opus-5-5"
gemini = "gemini-2.5-flash"
"""


def _default_models() -> dict[str, str]:
    return {"sonnet": "claude-sonnet-5-5", "opus": "claude-opus-5-5", "gemini": "gemini-2.5-flash"}


@dataclass
class Config:
    home: Path
    default_model: str = "sonnet"
    notes_dir: Path = field(default_factory=lambda: Path.home() / "Fixel Notes")
    recall_threshold: float = 0.6
    double_tap_window: float = 0.4
    thinking: bool = True
    max_tokens: int = 16000
    models: dict[str, str] = field(default_factory=_default_models)

    @property
    def config_path(self) -> Path:
        return self.home / "config.toml"

    @property
    def shots_dir(self) -> Path:
        return self.home / "shots"

    @property
    def casefile_path(self) -> Path:
        return self.home / "casefile.db"


def fixel_home() -> Path:
    return Path(os.environ.get("FIXEL_HOME", Path.home() / ".fixel")).expanduser()


def load_config(home: Path | None = None) -> Config:
    cfg = Config(home=home or fixel_home())
    if cfg.config_path.exists():
        data = tomllib.loads(cfg.config_path.read_text())
        for name in ("default_model", "recall_threshold", "double_tap_window", "thinking", "max_tokens"):
            if name in data:
                setattr(cfg, name, data[name])
        if "notes_dir" in data:
            cfg.notes_dir = Path(data["notes_dir"]).expanduser()
        cfg.models = {**cfg.models, **data.get("models", {})}
    return cfg


def write_default_config(cfg: Config) -> bool:
    """Create config.toml if it's missing. Returns True if it was created."""
    if cfg.config_path.exists():
        return False
    cfg.home.mkdir(parents=True, exist_ok=True)
    cfg.config_path.write_text(DEFAULT_CONFIG_TOML)
    return True


def provider_for_model(model_id: str) -> str:
    return "gemini" if model_id.startswith("gemini") else "anthropic"


def get_api_key(vendor: str) -> str | None:
    return os.environ.get(ENV_VARS[vendor]) or keyring.get_password(KEYRING_SERVICE, vendor)


def set_api_key(vendor: str, key: str) -> None:
    keyring.set_password(KEYRING_SERVICE, vendor, key)
````

````python
"""Right-Option double-tap detection.

DoubleTapDetector is pure timing logic. HotkeyListener feeds it from a macOS
Quartz listen-only event tap running on its own thread. We read raw keycodes
and never translate them to characters, which is what makes pynput crash on
recent macOS.
"""

from __future__ import annotations

import threading
import time
from dataclasses import dataclass
from typing import Callable

RIGHT_OPTION_KEYCODE = 61
RIGHT_OPTION_DEVICE_FLAG = 0x40  # NX_DEVICERALTKEYMASK


@dataclass
class DoubleTapDetector:
    window: float = 0.4
    _down: bool = False
    _chorded: bool = False  # another key was pressed while Right Option was held
    _last_tap: float | None = None

    def option_down(self, t: float) -> None:
        self._down = True
        self._chorded = False

    def other_key(self, t: float) -> None:
        if self._down:
            self._chorded = True
        self._last_tap = None  # any other key breaks a pending double-tap

    def option_up(self, t: float) -> bool:
        """Register a release; True when it completes a double-tap."""
        if not self._down:
            return False
        self._down = False
        if self._chorded:
            self._last_tap = None
            return False
        if self._last_tap is not None and t - self._last_tap <= self.window:
            self._last_tap = None  # consumed: a third tap starts a fresh pair
            return True
        self._last_tap = t
        return False


class HotkeyListener:
    def __init__(self, on_trigger: Callable[[], None], window: float = 0.4) -> None:
        self._detector = DoubleTapDetector(window=window)
        self._on_trigger = on_trigger
        self._tap = None

    def start(self) -> bool:
        """Start listening on a daemon thread. False if macOS refused (no Input Monitoring)."""
        import Quartz

        mask = Quartz.CGEventMaskBit(Quartz.kCGEventFlagsChanged) | Quartz.CGEventMaskBit(Quartz.kCGEventKeyDown)
        self._tap = Quartz.CGEventTapCreate(
            Quartz.kCGSessionEventTap,
            Quartz.kCGHeadInsertEventTap,
            Quartz.kCGEventTapOptionListenOnly,
            mask,
            self._callback,
            None,
        )
        if self._tap is None:
            return False

        def run() -> None:
            source = Quartz.CFMachPortCreateRunLoopSource(None, self._tap, 0)
            Quartz.CFRunLoopAddSource(Quartz.CFRunLoopGetCurrent(), source, Quartz.kCFRunLoopCommonModes)
            Quartz.CGEventTapEnable(self._tap, True)
            Quartz.CFRunLoopRun()

        threading.Thread(target=run, name="fixel-hotkey", daemon=True).start()
        return True

    def _callback(self, proxy, event_type, event, refcon):
        import Quartz

        if event_type in (Quartz.kCGEventTapDisabledByTimeout, Quartz.kCGEventTapDisabledByUserInput):
            Quartz.CGEventTapEnable(self._tap, True)
            return event
        now = time.monotonic()
        if event_type == Quartz.kCGEventKeyDown:
            self._detector.other_key(now)
        elif event_type == Quartz.kCGEventFlagsChanged:
            keycode = Quartz.CGEventGetIntegerValueField(event, Quartz.kCGKeyboardEventKeycode)
            if keycode != RIGHT_OPTION_KEYCODE:
                self._detector.other_key(now)
            elif Quartz.CGEventGetFlags(event) & RIGHT_OPTION_DEVICE_FLAG:
                self._detector.option_down(now)
            elif self._detector.option_up(now):
                self._on_trigger()
        return event
````

````python
"""Parse Fixel's hidden reply header and pull actionable pieces out of answers."""

from __future__ import annotations

import re
from dataclasses import dataclass

MODES = ("error", "math", "doc", "ui", "general")
HEADER_MAX = 400  # give up waiting for `---` after this many characters

_SEPARATOR = re.compile(r"^---[ \t]*$\n?", re.M)
_FENCE = re.compile(r"```([\w+-]*)[^\n]*\n(.*?)```", re.S)
_ANSWER_LINE = re.compile(r"^[ \t]*\**Answer:\**[ \t]*(.+?)[ \t]*$", re.M)
_SHELL_LANGS = {"bash", "sh", "zsh", "shell", "console"}


@dataclass(frozen=True)
class Header:
    mode: str = "general"
    key: str = ""


def split_header(text: str, final: bool = False) -> tuple[Header, str] | None:
    """Split a (possibly still-streaming) reply into (header, body).

    Returns None while more text is needed to decide. A reply that doesn't
    open with the header is treated as `general`, with the whole text as body.
    """
    stripped = text.lstrip()
    if not stripped.startswith("MODE:"):
        if "MODE:".startswith(stripped) and not final:
            return None
        return Header(), text
    separator = _SEPARATOR.search(stripped)
    if separator is None:
        if final or len(stripped) > HEADER_MAX:
            return Header(), text
        return None
    head, body = stripped[: separator.start()], stripped[separator.end() :]
    mode_match = re.search(r"^MODE:[ \t]*(\w+)", head, re.M)
    key_match = re.search(r"^KEY:[ \t]*(.*)$", head, re.M)
    mode = mode_match.group(1).lower() if mode_match else "general"
    key = key_match.group(1).strip() if key_match else ""
    return Header(mode if mode in MODES else "general", key), body.lstrip("\n")


def primary_fix(body: str) -> str | None:
    """What ⌃Y copies: the first code block, else the `Answer:` line, else the whole body."""
    fence = _FENCE.search(body)
    if fence:
        return fence.group(2).rstrip("\n")
    answer = _ANSWER_LINE.search(body)
    if answer:
        return answer.group(1)
    return body.strip() or None


def runnable_command(body: str) -> str | None:
    """What ⌃R may run: the first bash/sh/zsh block, with any `$ ` prompts removed."""
    for fence in _FENCE.finditer(body):
        if fence.group(1).lower() in _SHELL_LANGS:
            lines = [re.sub(r"^\$ ", "", line) for line in fence.group(2).strip("\n").splitlines()]
            command = "\n".join(lines).strip()
            if command:
                return command
    return None
````

````python
"""Deterministic provider for tests: replays canned replies in small chunks."""

from __future__ import annotations

from typing import AsyncIterator

from .base import Turn

DEFAULT_REPLY = "MODE: general\nKEY:\n---\nok"


class FakeProvider:
    def __init__(
        self,
        replies: list[str] | None = None,
        *,
        chunk: int = 7,
        error: Exception | None = None,
        error_after: int = 0,
    ) -> None:
        self.name = "fake"
        self.replies = list(replies or [])
        self.chunk = chunk
        self.error = error
        self.error_after = error_after  # chunks to yield before raising `error`
        self.calls: list[tuple[list[Turn], str]] = []

    async def stream(self, turns: list[Turn], system: str) -> AsyncIterator[str]:
        self.calls.append((list(turns), system))
        reply = self.replies.pop(0) if self.replies else DEFAULT_REPLY
        for sent, start in enumerate(range(0, len(reply), self.chunk)):
            if self.error is not None and sent >= self.error_after:
                raise self.error
            yield reply[start : start + self.chunk]
        if self.error is not None:
            raise self.error
````

````python
"""Claude via the official Anthropic SDK (streaming, prompt caching, adaptive thinking)."""

from __future__ import annotations

import base64
from typing import AsyncIterator

import anthropic

from .base import ProviderError, Turn


def to_messages(turns: list[Turn]) -> list[dict]:
    """Turns → Messages API params. One cache breakpoint on the newest block caches
    the system prompt plus every earlier screenshot for follow-up questions."""
    messages = []
    for turn in turns:
        content: list[dict] = [
            {
                "type": "image",
                "source": {"type": "base64", "media_type": "image/png", "data": base64.standard_b64encode(img).decode()},
            }
            for img in turn.images
        ]
        content.append({"type": "text", "text": turn.text})
        messages.append({"role": turn.role, "content": content})
    if messages:
        messages[-1]["content"][-1]["cache_control"] = {"type": "ephemeral"}
    return messages


class ClaudeProvider:
    def __init__(
        self,
        api_key: str,
        model: str,
        *,
        max_tokens: int = 16000,
        thinking: bool = True,
        client: anthropic.AsyncAnthropic | None = None,
    ) -> None:
        self.name = model
        self.model = model
        self.max_tokens = max_tokens
        self.thinking = thinking
        # The SDK already retries 429 / 5xx / connection errors twice with backoff.
        self._client = client or anthropic.AsyncAnthropic(api_key=api_key, max_retries=2)

    async def stream(self, turns: list[Turn], system: str) -> AsyncIterator[str]:
        params: dict = {
            "model": self.model,
            "max_tokens": self.max_tokens,
            "system": [{"type": "text", "text": system}],
            "messages": to_messages(turns),
        }
        if self.thinking:
            params["thinking"] = {"type": "adaptive"}
        try:
            async with self._client.messages.stream(**params) as stream:
                async for text in stream.text_stream:
                    yield text
        except anthropic.AuthenticationError as e:
            raise ProviderError("Anthropic rejected the API key. Run `fixel setup`.", auth=True) from e
        except anthropic.NotFoundError as e:
            raise ProviderError(
                f"Model '{self.model}' wasn't found. Fix [models] in ~/.fixel/config.toml or run `fixel setup`."
            ) from e
        except anthropic.RateLimitError as e:
            raise ProviderError("Anthropic is rate-limiting you (already retried). Wait a moment, then press Enter.") from e
        except anthropic.BadRequestError as e:
            hint = " (try `thinking = false` in ~/.fixel/config.toml)" if "thinking" in str(e.message).lower() else ""
            raise ProviderError(f"Anthropic rejected the request: {e.message}{hint}") from e
        except anthropic.APIConnectionError as e:
            raise ProviderError("Can't reach Anthropic. Check your internet, then press Enter.") from e
        except anthropic.APIStatusError as e:
            raise ProviderError(f"Anthropic error {e.status_code}: {e.message}") from e
````

````python
"""Gemini via the google-genai SDK."""

from __future__ import annotations

import asyncio
from typing import AsyncIterator

import httpx

from .base import ProviderError, Turn


def to_contents(turns: list[Turn]) -> list:
    from google.genai import types

    return [
        types.Content(
            role="user" if turn.role == "user" else "model",
            parts=[
                *(types.Part.from_bytes(data=img, mime_type="image/png") for img in turn.images),
                types.Part.from_text(text=turn.text),
            ],
        )
        for turn in turns
    ]


class GeminiProvider:
    def __init__(self, api_key: str, model: str, *, client=None) -> None:
        from google import genai

        self.name = model
        self.model = model
        self._client = client or genai.Client(api_key=api_key)

    async def stream(self, turns: list[Turn], system: str) -> AsyncIterator[str]:
        from google.genai import errors, types

        config = types.GenerateContentConfig(system_instruction=system)
        contents = to_contents(turns)
        for attempt in range(3):
            yielded = False
            try:
                chunks = await self._client.aio.models.generate_content_stream(
                    model=self.model, contents=contents, config=config
                )
                async for chunk in chunks:
                    if chunk.text:
                        yielded = True
                        yield chunk.text
                return
            except errors.APIError as e:
                code = e.code or 0
                if (code == 429 or code >= 500) and attempt < 2 and not yielded:
                    await asyncio.sleep(2**attempt)
                    continue
                message = e.message or str(e)
                if code in (401, 403) or "api key" in message.lower():
                    raise ProviderError("Google rejected the Gemini API key. Run `fixel setup`.", auth=True) from e
                if code == 404:
                    raise ProviderError(f"Gemini model '{self.model}' wasn't found. Fix it in ~/.fixel/config.toml.") from e
                if code == 429:
                    raise ProviderError("Gemini's rate limit hit (the free tier is small). Wait a minute, then press Enter.") from e
                raise ProviderError(f"Gemini error {code}: {message}") from e
            except httpx.TransportError as e:
                raise ProviderError("Can't reach Google. Check your internet, then press Enter.") from e
````

````python
"""Tray and case state. Pure logic apart from reading tray PNGs."""

from __future__ import annotations

from dataclasses import dataclass, field
from pathlib import Path

from .brain.base import Turn
from .parse import Header

MAX_TRAY = 5
DEFAULT_QUESTION = "Figure this out."


@dataclass
class Case:
    turns: list[Turn] = field(default_factory=list)
    shots: list[Path] = field(default_factory=list)
    header: Header | None = None
    question: str = ""  # the first question, used for notes and the case file
    answer: str = ""  # the latest answer body (header removed)
    case_id: int | None = None


@dataclass
class _Undo:
    case: Case
    turns: int
    shots: int
    question: str
    tray: list[Path]
    follow_up: bool


@dataclass
class Session:
    case: Case = field(default_factory=Case)
    tray: list[Path] = field(default_factory=list)
    follow_up: bool = False  # attach the next tray to the current case instead of starting a new one
    learn: bool = False
    _undo: _Undo | None = field(default=None, repr=False)

    def add_shot(self, path: Path) -> bool:
        if len(self.tray) >= MAX_TRAY:
            return False
        self.tray.append(path)
        return True

    def new_case(self) -> None:
        self.case = Case()
        self.tray = []
        self.follow_up = False

    def build_user_turn(self, text: str) -> Turn:
        """Move the tray + text into the conversation. A tray sent after an answer
        starts a new case unless follow-up is on; text alone always follows up."""
        case = self.case
        self._undo = _Undo(case, len(case.turns), len(case.shots), case.question, list(self.tray), self.follow_up)
        if self.tray and case.turns and not self.follow_up:
            self.case = Case()
        question = text.strip() or DEFAULT_QUESTION
        turn = Turn("user", question, [path.read_bytes() for path in self.tray])
        self.case.turns.append(turn)
        self.case.shots.extend(self.tray)
        if not self.case.question:
            self.case.question = question
        self.tray = []
        self.follow_up = False
        return turn

    def rollback(self) -> None:
        """Undo the last build_user_turn (the model call failed or was cancelled)."""
        undo = self._undo
        if undo is None:
            return
        self.case = undo.case
        del undo.case.turns[undo.turns :]
        del undo.case.shots[undo.shots :]
        undo.case.question = undo.question
        self.tray = undo.tray
        self.follow_up = undo.follow_up
        self._undo = None

    def record_answer(self, header: Header, raw: str, body: str) -> None:
        previous = self.case.header
        self.case.header = header if previous is None else Header(header.mode, header.key or previous.key)
        self.case.turns.append(Turn("assistant", raw))
        self.case.answer = body
        self._undo = None
````

````python
from __future__ import annotations

import json
import re
import sqlite3
from dataclasses import dataclass
from datetime import datetime
from pathlib import Path

_SCHEMA = """
CREATE TABLE IF NOT EXISTS cases (
  id INTEGER PRIMARY KEY,
  created_at TEXT NOT NULL,
  mode TEXT NOT NULL,
  key TEXT NOT NULL,
  question TEXT NOT NULL,
  answer TEXT NOT NULL,
  shot_paths TEXT NOT NULL
);
CREATE VIRTUAL TABLE IF NOT EXISTS cases_fts USING fts5(key, question, answer);
"""


def tokens(text: str) -> set[str]:
    return set(re.findall(r"[a-z0-9_]{2,}", text.lower()))


def _match_any(words: set[str]) -> str:
    return " OR ".join(f'"{w}"' for w in sorted(words))


@dataclass(frozen=True)
class CaseRecord:
    id: int
    created_at: datetime
    mode: str
    key: str
    question: str
    answer: str
    shot_paths: list[str]


class CaseFile:
    def __init__(self, path: Path) -> None:
        path.parent.mkdir(parents=True, exist_ok=True)
        self._db = sqlite3.connect(path)
        self._db.executescript(_SCHEMA)

    def save(
        self,
        *,
        case_id: int | None,
        mode: str,
        key: str,
        question: str,
        answer: str,
        shot_paths: list,
        now: datetime | None = None,
    ) -> int:
        shots = json.dumps([str(p) for p in shot_paths])
        with self._db:
            if case_id is None:
                created = (now or datetime.now()).isoformat(timespec="seconds")
                cursor = self._db.execute(
                    "INSERT INTO cases (created_at, mode, key, question, answer, shot_paths) VALUES (?, ?, ?, ?, ?, ?)",
                    (created, mode, key, question, answer, shots),
                )
                case_id = cursor.lastrowid
            else:
                self._db.execute(
                    "UPDATE cases SET mode = ?, key = ?, question = ?, answer = ?, shot_paths = ? WHERE id = ?",
                    (mode, key, question, answer, shots, case_id),
                )
                self._db.execute("DELETE FROM cases_fts WHERE rowid = ?", (case_id,))
            self._db.execute(
                "INSERT INTO cases_fts (rowid, key, question, answer) VALUES (?, ?, ?, ?)",
                (case_id, key, question, answer),
            )
        return case_id

    def get(self, case_id: int) -> CaseRecord | None:
        row = self._db.execute(
            "SELECT id, created_at, mode, key, question, answer, shot_paths FROM cases WHERE id = ?", (case_id,)
        ).fetchone()
        if row is None:
            return None
        cid, created, mode, key, question, answer, shots = row
        return CaseRecord(cid, datetime.fromisoformat(created), mode, key, question, answer, json.loads(shots))

    def recall(self, key: str, *, exclude_id: int | None, threshold: float = 0.6) -> CaseRecord | None:
        """The most similar past case by key-token overlap (Jaccard), if it clears `threshold`."""
        wanted = tokens(key)
        if not wanted:
            return None
        rows = self._db.execute(
            "SELECT rowid FROM cases_fts WHERE cases_fts MATCH ? ORDER BY rank LIMIT 10",
            (f"key : ({_match_any(wanted)})",),
        ).fetchall()
        best, best_score = None, 0.0
        for (rowid,) in rows:
            if rowid == exclude_id:
                continue
            record = self.get(rowid)
            if record is None:
                continue
            theirs = tokens(record.key)
            score = len(wanted & theirs) / len(wanted | theirs)
            if score > best_score:
                best, best_score = record, score
        return best if best_score >= threshold else None

    def search(self, query: str, limit: int = 10) -> list[CaseRecord]:
        words = tokens(query)
        if not words:
            return []
        rows = self._db.execute(
            "SELECT rowid FROM cases_fts WHERE cases_fts MATCH ? ORDER BY rank LIMIT ?", (_match_any(words), limit)
        ).fetchall()
        return [record for (rowid,) in rows if (record := self.get(rowid)) is not None]
````

````python
"""Region screenshots via macOS's built-in `screencapture`."""

from __future__ import annotations

import asyncio
import struct
from pathlib import Path

MAX_EDGE = 1568  # Claude downsamples beyond this anyway; also keeps PNGs well under the 5 MB limit


def png_size(data: bytes) -> tuple[int, int]:
    if len(data) < 24 or data[:8] != b"\x89PNG\r\n\x1a\n":
        raise ValueError("not a PNG")
    return struct.unpack(">II", data[16:24])


async def _run(*args: str) -> int:
    proc = await asyncio.create_subprocess_exec(
        *args, stdout=asyncio.subprocess.DEVNULL, stderr=asyncio.subprocess.DEVNULL
    )
    return await proc.wait()


async def capture_region(dest: Path) -> bytes | None:
    """Let the user drag-select a region and save it to `dest`. None if they pressed Esc."""
    dest.parent.mkdir(parents=True, exist_ok=True)
    await _run("screencapture", "-i", "-x", str(dest))
    if not dest.exists() or dest.stat().st_size == 0:
        return None
    data = dest.read_bytes()
    if max(png_size(data)) > MAX_EDGE:
        await _run("sips", "-Z", str(MAX_EDGE), str(dest))
        data = dest.read_bytes()
    return data
````

````python
"""Terminal.app glue: open Fixel in its own window, and bring that window forward."""

from __future__ import annotations

import asyncio
import os
import shlex
import subprocess
import sys

WINDOW_TITLE = "Fixel"


def applescript_string(s: str) -> str:
    return '"' + s.replace("\\", "\\\\").replace('"', '\\"') + '"'


def launch_command() -> str:
    return f"clear; FIXEL_INSIDE=1 exec {shlex.quote(sys.executable)} -m fixel"


def open_in_terminal_app() -> bool:
    script = f'tell application "Terminal"\n  activate\n  do script {applescript_string(launch_command())}\nend tell'
    return subprocess.run(["osascript", "-e", script], capture_output=True).returncode == 0


def set_title(title: str = WINDOW_TITLE) -> None:
    sys.stdout.write(f"\033]0;{title}\007")
    sys.stdout.flush()


def front_window_id() -> int | None:
    """Terminal.app's id for the window we're running in (it's frontmost at startup)."""
    if os.environ.get("TERM_PROGRAM") != "Apple_Terminal":
        return None
    result = subprocess.run(
        ["osascript", "-e", 'tell application "Terminal" to id of front window'], capture_output=True, text=True
    )
    try:
        return int(result.stdout.strip())
    except ValueError:
        return None


async def raise_window(window_id: int | None) -> None:
    if window_id is None:
        return
    script = f'tell application "Terminal"\n  set index of window id {window_id} to 1\n  activate\nend tell'
    proc = await asyncio.create_subprocess_exec(
        "osascript", "-e", script, stdout=asyncio.subprocess.DEVNULL, stderr=asyncio.subprocess.DEVNULL
    )
    await proc.wait()
````

````python
"""One-key actions: copy the fix, run a confirmed command, save a note."""

from __future__ import annotations

import asyncio
import os
import re
import shutil
import signal
import subprocess
from datetime import datetime
from pathlib import Path


def copy_to_clipboard(text: str) -> None:
    subprocess.run(["pbcopy"], input=text.encode(), check=True)


async def run_command(cmd: str, *, timeout: float = 60.0, cwd: Path | None = None) -> tuple[int | None, str]:
    """Run an already-confirmed command in zsh. Returns (exit code, or None on timeout; combined output)."""
    proc = await asyncio.create_subprocess_exec(
        "/bin/zsh", "-c", cmd,
        cwd=str(cwd or Path.home()),
        stdout=asyncio.subprocess.PIPE,
        stderr=asyncio.subprocess.STDOUT,
        start_new_session=True,  # so a timeout can kill the whole process group
    )
    try:
        out, _ = await asyncio.wait_for(proc.communicate(), timeout)
    except asyncio.TimeoutError:
        os.killpg(proc.pid, signal.SIGKILL)
        out, _ = await proc.communicate()
        return None, out.decode(errors="replace") + f"\n[stopped after {timeout:g}s]"
    return proc.returncode, out.decode(errors="replace")


def slugify(text: str, max_len: int = 40) -> str:
    slug = re.sub(r"[^a-z0-9]+", "-", text.lower()).strip("-")[:max_len].strip("-")
    return slug or "note"


def save_note(
    notes_dir: Path,
    *,
    question: str,
    answer: str,
    mode: str,
    shots: list[Path],
    when: datetime | None = None,
) -> Path:
    when = when or datetime.now()
    notes_dir.mkdir(parents=True, exist_ok=True)
    base = f"{when:%Y-%m-%d}-{slugify(question)}"
    path, n = notes_dir / f"{base}.md", 2
    while path.exists():
        path, n = notes_dir / f"{base}-{n}.md", n + 1
    lines = [f"# {question}", "", f"*{mode} · {when:%Y-%m-%d %H:%M}*", ""]
    existing = [shot for shot in shots if Path(shot).exists()]
    if existing:
        attachments = notes_dir / "attachments"
        attachments.mkdir(exist_ok=True)
        for i, shot in enumerate(existing, 1):
            target = attachments / f"{path.stem}-{i}.png"
            shutil.copyfile(shot, target)
            lines.append(f"![screenshot {i}](attachments/{target.name})")
        lines.append("")
    lines += [answer.strip(), ""]
    path.write_text("\n".join(lines))
    return path
````

````python
import time
from dataclasses import dataclass

from rich.console import Console, Group
from rich.live import Live
from rich.markdown import Markdown
from rich.panel import Panel
from rich.spinner import Spinner
from rich.syntax import Syntax
from rich.text import Text

from .parse import Header, split_header

BADGES = {
    "error": "bold white on red",
    "math": "bold black on cyan",
    "doc": "bold black on yellow",
    "ui": "bold white on blue",
    "general": "bold black on white",
}
ACTION_KEYS = (
    ("c-y", "copy"),
    ("c-r", "run"),
    ("c-s", "save"),
    ("c-l", "learn"),
    ("c-f", "follow"),
    ("c-o", "open"),
    ("c-n", "new"),
)
HELP = """\
**Screenshot:** double-tap **Right Option ⌥**, then drag over anything. Shots wait in the tray; \
double-tap again to add more (up to 5).
**Ask:** press **Enter**, or type a question first. Typing after an answer asks a follow-up.

| Key | Does |
|---|---|
| ⌃Y | copy the fix / answer / draft |
| ⌃R | run the suggested shell command (asks first) |
| ⌃S | save this case as a note in ~/Fixel Notes |
| ⌃L | learn mode: hints instead of answers (`/answer` reveals) |
| ⌃F | attach the tray to the current case instead of starting a new one |
| ⌃O | open the "Seen before" case |
| ⌃N | new case |

**Commands:** `/model sonnet|opus|gemini` · `/answer` · `/cases <words>` · `/open <number>` · `/help` · `/quit`
"""


@dataclass(frozen=True)
class KeyAction:
    name: str
    buffer: str  # whatever was typed, restored after the action


@dataclass
class Status:
    """What the bottom toolbar shows. The app writes it; the toolbar reads it every refresh."""

    tray: int = 0
    follow_up: bool = False
    hotkey_ok: bool = True
    flash: str = ""
    flash_until: float = 0.0

    def flash_msg(self, msg: str, seconds: float = 4.0) -> None:
        self.flash = msg
        self.flash_until = time.monotonic() + seconds


def toolbar_text(status: Status) -> str:
    if status.flash and time.monotonic() < status.flash_until:
        return status.flash
    if status.tray:
        plural = "" if status.tray == 1 else "s"
        follow = "on" if status.follow_up else "off"
        return f"📸 {status.tray} shot{plural} in tray · ⏎ ask · ⌥⌥ add more · ⌃F follow-up: {follow}"
    hotkey = "⌥⌥ screenshot" if status.hotkey_ok else "⚠ hotkey off (run fixel setup)"
    return f"{hotkey} · ⌃Y copy · ⌃R run · ⌃S save · ⌃L learn · ⌃N new · /help"


class UI:
    def __init__(self, console: Console | None = None) -> None:
        self.console = console or Console()
        self.status = Status()
        self._session: PromptSession | None = None

    # ---- input

    def _prompt_session(self) -> PromptSession:
        if self._session is None:
            bindings = KeyBindings()
            for key, name in ACTION_KEYS:
                bindings.add(key)(self._action_handler(name))
            self._session = PromptSession(
                key_bindings=bindings, bottom_toolbar=lambda: toolbar_text(self.status), refresh_interval=0.3
            )
        return self._session

    @staticmethod
    def _action_handler(name: str):
        def handler(event) -> None:
            event.app.exit(result=KeyAction(name, event.app.current_buffer.text))

        return handler

    async def prompt(self, default: str = "") -> str | KeyAction | None:
        """Read one line. ⌃-keys return a KeyAction; ⌃D returns None; ⌃C clears the line."""
        with patch_stdout(raw=True):
            try:
                return await self._prompt_session().prompt_async(HTML("<ansicyan><b>›</b></ansicyan> "), default=default)
            except KeyboardInterrupt:
                return ""
            except EOFError:
                return None

    async def confirm(self, question: str) -> bool:
        try:
            reply = await PromptSession().prompt_async(question)
        except (KeyboardInterrupt, EOFError):
            return False
        return reply.strip().lower() in ("y", "yes")

    # ---- output

    def banner(self, model: str, learn: bool) -> None:
        self.console.rule(f"[bold cyan]Fixel[/] · {model} · learn: {'on' if learn else 'off'}")

    def info(self, msg: str) -> None:
        self.console.print(f"[cyan]›[/] {msg}")

    def warn(self, msg: str) -> None:
        self.console.print(f"[yellow]⚠ {msg}[/]")

    def error(self, msg: str) -> None:
        self.console.print(f"[bold red]✖ {msg}[/]")

    def help(self) -> None:
        self.console.print(Markdown(HELP))

    @staticmethod
    def answer_view(header: Header | None, body: str):
        if header is None:
            return Spinner("dots", text=" thinking…")
        title = Text(f" {header.mode.upper()} ", style=BADGES.get(header.mode, BADGES["general"]))
        if header.key:
            title.append(f"  {header.key}", style="dim")
        return Group(title, Text(""), Markdown(body, code_theme="monokai"))

    async def stream_answer(self, chunks: AsyncIterator[str]) -> tuple[Header, str, str]:
        """Render a streaming reply live, hiding the header. Returns (header, raw reply, body)."""
        raw = ""
        with Live(self.answer_view(None, ""), console=self.console, refresh_per_second=12, vertical_overflow="visible") as live:
            async for chunk in chunks:
                raw += chunk
                parsed = split_header(raw)
                if parsed is not None:
                    live.update(self.answer_view(*parsed))
            header, body = split_header(raw, final=True)
            live.update(self.answer_view(header, body))
        return header, raw, body

    def recall_line(self, record) -> None:
        self.console.print(f"[magenta]📁 Seen before: {record.created_at:%b %d} — {record.key}  (⌃O to open)[/]")

    def action_bar(self) -> None:
        self.console.print(Text("─" * min(self.console.width, 72), style="dim"))
        self.console.print("[dim]⌃Y copy · ⌃R run · ⌃S save note · ⌃L learn · ⌃N new[/]")

    def show_command(self, cmd: str) -> None:
        self.console.print(Panel(Syntax(cmd, "bash", theme="monokai", word_wrap=True), title="Run this?", border_style="yellow"))

    def show_output(self, code: int | None, out: str) -> None:
        title = "timed out" if code is None else f"exit {code}"
        style = "green" if code == 0 else "red"
        self.console.print(Panel(Text(out.rstrip() or "(no output)"), title=title, border_style=style))

    def show_case(self, record) -> None:
        title = f"#{record.id} · {record.created_at:%Y-%m-%d} · {record.mode} · {record.key or record.question}"
        self.console.print(Panel(Markdown(record.answer), title=title, border_style="magenta"))

    def show_cases(self, records) -> None:
        for r in records:
            self.console.print(f"[bold]#{r.id}[/] {r.created_at:%Y-%m-%d} [dim]{r.mode}[/] {r.key or r.question[:70]}")
        self.console.print("[dim]Open one with /open <number>[/]")
````

````python
"""Fixel's main loop: wires hotkey, capture, model, memory, and UI together."""

from __future__ import annotations

import asyncio
import signal
import sqlite3
import uuid
from pathlib import Path
from typing import Awaitable, Callable

from . import actions, permissions
from .brain import Provider, ProviderError, make_provider
from .capture import capture_region
from .casefile import CaseFile, CaseRecord
from .config import Config
from .hotkey import HotkeyListener
from .parse import primary_fix, runnable_command
from .prompts import build_system
from .session import MAX_TRAY, Session
from .ui import UI, KeyAction


class FixelApp:
    def __init__(
        self,
        cfg: Config,
        ui: UI,
        *,
        provider_factory: Callable[[str, Config], Provider] = make_provider,
        capture: Callable[[Path], Awaitable[bytes | None]] = capture_region,
        raise_window: Callable[[], Awaitable[None]] | None = None,
        casefile: CaseFile | None = None,
    ) -> None:
        self.cfg = cfg
        self.ui = ui
        self.session = Session()
        self.provider: Provider | None = None
        self.model_alias = cfg.default_model
        self.casefile = casefile
        self.last_recall: CaseRecord | None = None
        self.screen_ok = True
        self._provider_factory = provider_factory
        self._capture = capture
        self._raise_window = raise_window
        self._hotkeys: asyncio.Queue[None] = asyncio.Queue()

    # ---- startup

    def select_model(self, alias: str) -> bool:
        try:
            self.provider = self._provider_factory(alias, self.cfg)
        except ProviderError as e:
            self.ui.error(str(e))
            return False
        self.model_alias = alias
        return True

    def _open_casefile(self) -> None:
        if self.casefile is not None:
            return
        try:
            self.casefile = CaseFile(self.cfg.casefile_path)
        except sqlite3.Error as e:
            self.ui.warn(f"Case file unavailable ({e}); memory is off this session.")

    def _start_hotkey(self) -> None:
        loop = asyncio.get_running_loop()
        app_name = permissions.host_app()
        listener = HotkeyListener(
            lambda: loop.call_soon_threadsafe(self._hotkeys.put_nowait, None), window=self.cfg.double_tap_window
        )
        hotkey_ok = permissions.input_monitoring_granted() and listener.start()
        self.ui.status.hotkey_ok = hotkey_ok
        if not hotkey_ok:
            self.ui.error(
                f"Hotkey is off: allow {app_name} in System Settings → Privacy & Security → Input Monitoring, "
                "then reopen it. `fixel setup` walks you through it."
            )
        self.screen_ok = permissions.screen_recording_granted()
        if not self.screen_ok:
            self.ui.error(
                f"Screenshots are off: allow {app_name} in System Settings → Privacy & Security → "
                "Screen & System Audio Recording, then reopen it."
            )

    async def run(self) -> None:
        self._open_casefile()
        self.select_model(self.cfg.default_model)
        self.ui.banner(self.provider.name if self.provider else "no model", self.session.learn)
        self._start_hotkey()
        self.ui.info("Double-tap Right Option ⌥ to screenshot. /help for keys.")
        capture_task = asyncio.create_task(self._capture_worker())
        pending = ""
        try:
            while True:
                result = await self.ui.prompt(default=pending)
                pending = ""
                if result is None:
                    break
                if isinstance(result, KeyAction):
                    pending = result.buffer
                    await self.handle_action(result.name)
                    continue
                text = result.strip()
                if text.startswith("/"):
                    if not await self.handle_command(text):
                        break
                elif text or self.session.tray:
                    pending = await self.ask(text)
        finally:
            capture_task.cancel()

    # ---- capture

    async def _capture_worker(self) -> None:
        while True:
            await self._hotkeys.get()
            await self.capture_once()
            while not self._hotkeys.empty():  # drop taps made during the selection
                self._hotkeys.get_nowait()

    async def capture_once(self) -> None:
        status = self.ui.status
        if not self.screen_ok:
            status.flash_msg("⚠ Screen Recording permission is missing. Run `fixel setup`.")
            return
        if len(self.session.tray) >= MAX_TRAY:
            status.flash_msg(f"Tray is full ({MAX_TRAY} shots). Press Enter to ask.")
            return
        path = self.cfg.shots_dir / f"{uuid.uuid4().hex}.png"
        if await self._capture(path):
            self.session.add_shot(path)
        self._sync_status()
        if self._raise_window is not None:
            await self._raise_window()

    def _sync_status(self) -> None:
        self.ui.status.tray = len(self.session.tray)
        self.ui.status.follow_up = self.session.follow_up

    # ---- asking

    async def ask(self, text: str) -> str:
        """Send the tray + text. Returns text to put back at the prompt (empty on success)."""
        if self.provider is None:
            self.ui.error("No model is ready. Run `fixel setup`, then `/model sonnet`.")
            return text
        self.session.build_user_turn(text)
        self._sync_status()
        system = build_system(self.session.learn)
        task = asyncio.ensure_future(self.ui.stream_answer(self.provider.stream(list(self.session.case.turns), system)))
        loop = asyncio.get_running_loop()
        try:
            loop.add_signal_handler(signal.SIGINT, task.cancel)  # ⌃C stops the answer, not Fixel
            interruptible = True
        except (NotImplementedError, RuntimeError, ValueError):
            interruptible = False
        try:
            header, raw, body = await task
        except asyncio.CancelledError:
            if not task.cancelled():
                raise
            self.session.rollback()
            self._sync_status()
            self.ui.warn("Stopped.")
            return text
        except ProviderError as e:
            self.session.rollback()
            self._sync_status()
            hint = " Your screenshots are still in the tray. Press Enter to retry." if self.session.tray else ""
            self.ui.error(f"{e}{hint}")
            return text
        finally:
            if interruptible:
                loop.remove_signal_handler(signal.SIGINT)
        self.session.record_answer(header, raw, body)
        self._remember()
        self.ui.action_bar()
        return ""

    def _remember(self) -> None:
        case = self.session.case
        if self.casefile is None or case.header is None:
            return
        first_answer = len(case.turns) == 2
        try:
            case.case_id = self.casefile.save(
                case_id=case.case_id, mode=case.header.mode, key=case.header.key,
                question=case.question, answer=case.answer, shot_paths=case.shots,
            )
            record = None
            if first_answer and case.header.key:
                record = self.casefile.recall(
                    case.header.key, exclude_id=case.case_id, threshold=self.cfg.recall_threshold
                )
        except sqlite3.Error as e:
            self.ui.warn(f"Case file error ({e}); memory is off this session.")
            self.casefile = None
            return
        if first_answer:
            self.last_recall = record
        if record is not None:
            self.ui.recall_line(record)

    # ---- keys and commands

    async def handle_action(self, name: str) -> None:
        case = self.session.case
        if name == "copy":
            fix = primary_fix(case.answer) if case.answer else None
            if not fix:
                self.ui.warn("Nothing to copy yet.")
                return
            actions.copy_to_clipboard(fix)
            self.ui.info(f"Copied {len(fix)} characters to the clipboard.")
        elif name == "run":
            command = runnable_command(case.answer) if case.answer else None
            if not command:
                self.ui.warn("This answer has no shell command to run.")
                return
            self.ui.show_command(command)
            if not await self.ui.confirm("Type y to run it (anything else cancels): "):
                self.ui.info("Cancelled. Nothing ran.")
                return
            code, output = await actions.run_command(command)
            self.ui.show_output(code, output)
        elif name == "save":
            if not case.answer:
                self.ui.warn("Nothing to save yet.")
                return
            mode = case.header.mode if case.header else "general"
            path = actions.save_note(
                self.cfg.notes_dir, question=case.question, answer=case.answer, mode=mode, shots=case.shots
            )
            self.ui.info(f"Saved {path}")
        elif name == "learn":
            self.session.learn = not self.session.learn
            if self.session.learn:
                self.ui.info("Learn mode on: you'll get hints and guiding questions. Send /answer for the full solution.")
            else:
                self.ui.info("Learn mode off: full answers.")
        elif name == "follow":
            if not self.session.tray:
                self.ui.warn("Take a screenshot first (⌥⌥), then press ⌃F to attach it to this case.")
                return
            self.session.follow_up = not self.session.follow_up
            self._sync_status()
            where = "added to the current case" if self.session.follow_up else "a new case"
            self.ui.info(f"The tray will go to {where}.")
        elif name == "open":
            if self.last_recall is None:
                self.ui.warn("No past case to open.")
            else:
                self.ui.show_case(self.last_recall)
        elif name == "new":
            self.session.new_case()
            self.last_recall = None
            self._sync_status()
            self.ui.info("New case. Double-tap ⌥ to screenshot.")

    async def handle_command(self, text: str) -> bool:
        """Run a slash command. Returns False when Fixel should quit."""
        command, _, arg = text.partition(" ")
        arg = arg.strip()
        if command in ("/quit", "/exit"):
            return False
        if command == "/help":
            self.ui.help()
        elif command == "/model":
            if not arg:
                current = self.provider.name if self.provider else "none"
                self.ui.info(f"Model: {self.model_alias} ({current}). Options: {', '.join(self.cfg.models)}")
            elif self.select_model(arg):
                self.ui.banner(self.provider.name, self.session.learn)
        elif command == "/answer":
            if not self.session.learn:
                self.ui.info("Learn mode is off, so answers are already complete.")
            elif not self.session.case.turns:
                self.ui.warn("Nothing to answer yet.")
            else:
                await self.ask("/answer")
        elif command == "/cases":
            if self.casefile is None:
                self.ui.warn("Memory is off this session.")
            elif not arg:
                self.ui.warn("Usage: /cases <words to search for>")
            else:
                records = self.casefile.search(arg)
                if records:
                    self.ui.show_cases(records)
                else:
                    self.ui.info("No matching cases.")
        elif command == "/open":
            record = self.casefile.get(int(arg)) if self.casefile and arg.isdigit() else None
            if record is None:
                self.ui.warn("Usage: /open <number from /cases>")
            else:
                self.ui.show_case(record)
        else:
            self.ui.warn(f"Unknown command {command}. Try /help.")
        return True
````

````python
"""`fixel setup`: save API keys to the Keychain, check them, and walk through macOS permissions."""

from __future__ import annotations

import getpass

from rich.console import Console

from . import permissions
from .config import Config, get_api_key, set_api_key, write_default_config


def _check_anthropic(key: str, model: str) -> str:
    import anthropic

    client = anthropic.Anthropic(api_key=key, max_retries=1)
    try:
        client.models.retrieve(model)
        return f"[green]✔ Key works and {model} is available.[/]"
    except anthropic.AuthenticationError:
        return "[red]✖ Anthropic rejected this key.[/]"
    except anthropic.NotFoundError:
        ids = ", ".join(m.id for m in client.models.list(limit=20))
        return f"[yellow]⚠ Key works, but '{model}' wasn't found. Available: {ids}. Update [models] in ~/.fixel/config.toml.[/]"
    except anthropic.APIConnectionError:
        return "[yellow]⚠ Couldn't reach Anthropic to check the key (it's saved anyway).[/]"


def _check_gemini(key: str, model: str) -> str:
    from google import genai
    from google.genai import errors

    try:
        genai.Client(api_key=key).models.get(model=model)
        return f"[green]✔ Key works and {model} is available.[/]"
    except errors.APIError as e:
        if e.code == 404:
            return f"[yellow]⚠ Key works, but '{model}' wasn't found. Update [models] in ~/.fixel/config.toml.[/]"
        return f"[red]✖ Google rejected this key ({e.code}).[/]"
    except Exception:
        return "[yellow]⚠ Couldn't reach Google to check the key (it's saved anyway).[/]"


def run_setup(cfg: Config, console: Console | None = None) -> None:
    console = console or Console()
    console.rule("[bold cyan]Fixel setup")
    if write_default_config(cfg):
        console.print(f"Created {cfg.config_path}")

    providers = (
        ("anthropic", "Anthropic (Claude)", "sonnet", "https://console.anthropic.com/settings/keys", _check_anthropic),
        ("gemini", "Google Gemini (optional)", "gemini", "https://aistudio.google.com/apikey", _check_gemini),
    )
    for vendor, label, alias, url, check in providers:
        key = get_api_key(vendor)
        console.print(f"\n[bold]{label}[/]: key {'saved' if key else 'not set'}. Get one at {url}")
        entered = getpass.getpass("Paste key (hidden; press Enter to keep/skip): ").strip()
        if entered:
            set_api_key(vendor, entered)
            key = entered
            console.print("Saved to the macOS Keychain.")
        if key:
            console.print(check(key, cfg.models[alias]))

    app_name = permissions.host_app()
    console.print(f"\n[bold]Permissions[/] (macOS grants these to {app_name}):")
    checks = (
        ("Input Monitoring: the ⌥⌥ hotkey", permissions.input_monitoring_granted, permissions.request_input_monitoring, permissions.INPUT_MONITORING_URL),
        ("Screen Recording: screenshots", permissions.screen_recording_granted, permissions.request_screen_recording, permissions.SCREEN_RECORDING_URL),
    )
    for name, granted, request, url in checks:
        if granted():
            console.print(f"[green]✔ {name}[/]")
            continue
        request()
        permissions.open_settings(url)
        console.print(f"[yellow]⚠ {name}: switch on {app_name} in the Settings page that just opened, then quit and reopen {app_name}.[/]")
    console.print("\nDone. Start Fixel with: [bold]fixel[/]")
````

````python
    from .config import load_config

    cfg = load_config()
    if args.command == "setup":
        from .setup import run_setup

        return 0

    from . import terminal

    if not args.here and os.environ.get("FIXEL_INSIDE") != "1":
        if terminal.open_in_terminal_app():
            print("Fixel opened in a new Terminal window.")
            return 0
        print("Couldn't open Terminal.app, so running here instead.")

    window_id = terminal.front_window_id()
    await FixelApp(cfg, UI(), raise_window=lambda: terminal.raise_window(window_id)).run()
    return 0


if __name__ == "__main__":
    sys.exit(main())
````

````markdown
# Fixel: Dylan's Personal AI

Double-tap **Right Option ⌥**, drag over anything on screen, and Fixel answers in its own Terminal window.

Fixel recognizes what you captured and answers in the format that fits:

| You screenshot… | You get… |
|---|---|
| an error, stack trace, or broken code | the cause, plus the fix as a paste-ready command or diff |
| a math or homework problem | numbered steps and a final `Answer:` |
| an email, doc, or spreadsheet | a short summary plus a ready-to-use draft or formula |
| a confusing app screen | exact click-by-click steps |

**What sets it apart**

- **Case file:** every solved problem is saved on your Mac. Hit the same error again and Fixel says *"Seen before: Sep 12"* (⌃O opens it).
- **One-key actions:** ⌃Y copies the fix, ⌃R runs the suggested command (only after you type `y`), ⌃S saves a Markdown note.
- **Stack shots:** double-tap again before asking to add more screenshots (error + code + config) to one question.
- **Learn mode:** ⌃L switches to hints and guiding questions instead of answers; `/answer` reveals the full solution.

## Install

/opt/homebrew/bin/python3.12 -m venv .venv

ln -sf "$PWD/.venv/bin/fixel" /opt/homebrew/bin/fixel   # makes `fixel` work everywhere

## Set up (once)

Run this **in Terminal.app**, because macOS grants permissions to the app Fixel runs inside:

```bash
fixel setup
```

It will:
1. Ask for your **Anthropic API key** ([console.anthropic.com](https://console.anthropic.com/settings/keys)) and, optionally, a **Gemini key** ([aistudio.google.com](https://aistudio.google.com/apikey)). Keys go into the macOS Keychain, never into a file.
2. Check that the key works and the model exists.
3. Open System Settings for **Input Monitoring** (the hotkey) and **Screen Recording** (screenshots). Switch Terminal on in both, then quit and reopen Terminal.

## Use

```bash
fixel           # opens Fixel in its own Terminal window
fixel --here    # runs in the current terminal instead
```

| Key | Does |
|---|---|
| ⌥⌥ (Right Option twice) | screenshot a region into the tray |
| Enter | ask (type a question first, or just press Enter) |
| ⌃Y / ⌃R / ⌃S | copy fix / run command / save note |
| ⌃L | learn mode |
| ⌃F | attach the tray to the current case instead of starting a new one |
| ⌃O | open the "Seen before" case |
| ⌃N | new case |
| ⌃C | stop an answer that's streaming |

Commands: `/model sonnet|opus|gemini`, `/answer`, `/cases <words>`, `/open <n>`, `/help`, `/quit`.

## Customize

- `~/.fixel/config.toml` sets the default model, model IDs, the double-tap speed, the notes folder, and how strict "Seen before" matching is.
- `fixel/prompts.py` holds Fixel's personality and answer formats. Edit it to change how Fixel talks.

## Privacy & cost

Screenshots go only to the model provider you've selected (Anthropic or Google). The case file, notes, and screenshots stay in `~/.fixel` and `~/Fixel Notes`. Claude bills per use, typically a fraction of a cent to a few cents per question; Opus costs more than Sonnet. Gemini has a free tier with rate limits.
````
