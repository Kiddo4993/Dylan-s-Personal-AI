Fixel

Screenshot what you're stuck on. Read the fix in your terminal.

How it works

Press ⌥ ⌥ (Right Option, twice) in any app and drag over an error, a math problem, an email or a webpage. Fixel works out what kind of problem it is and answers in the format that fits: the fix as a command you can run, numbered steps, a draft reply, or an HTML file that recreates the page.

It remembers what worked. When an error you've solved before comes back, Fixel hands the AI the fix that worked last time. It runs on your own Claude, Gemini or OpenAI key, kept in the macOS Keychain, with no account and no server.

Made for students too

Learn mode gives hints instead of answers. A built-in IDE runs Python, Java, JavaScript and C++ in its own Terminal window. /canvas lists what's due on Canvas with a priority, an hours estimate, a start-by date and a tip for each assignment, and can keep a Notion database in sync.

Install

macOS with Python 3.11 or newer.

git clone https://github.com/Kiddo4993/fixel.git && cd fixel
python3 -m venv .venv && .venv/bin/pip install -e .
.venv/bin/fixel setup

Using Claude Code? /plugin install fixel --marketplace Kiddo4993/fixel lets Claude look at your screen, check your homework, and search your past fixes.
